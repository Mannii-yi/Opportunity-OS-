# OpportunityOS

OpportunityOS is a hackathon MVP that helps students discover opportunities they are eligible for today and understand what skills they should learn next to unlock more opportunities tomorrow.

## Problem

Students miss internships, scholarships, fellowships, research programs, hackathons, and competitions because they do not know:

- Which opportunities exist
- Whether they are eligible
- What requirements they are missing
- What to learn next for the biggest career impact

## Solution

OpportunityOS turns a student profile into:

- Eligible opportunities
- Near eligible opportunities
- Missing skills and requirements
- Ranked skill recommendations
- A simple roadmap to become eligible for more opportunities

## Core Innovation

Most platforms answer:

> What can I apply for today?

OpportunityOS answers:

> What should I learn next to unlock more opportunities tomorrow?

## Tech Stack

- React
- Vite
- Local JSON dataset
- Rule-based matching engine
- Frontend-only architecture

## Demo Flow

1. Open the app.
2. Select a sample student profile.
3. View eligible and near eligible opportunities.
4. Show missing skills and gaps.
5. Highlight the best next skill from the unlock engine.
6. Show the roadmap for that skill.
